# Лабораторная работа № 2 — Числа Мерсенна

Дисциплина: «Современные языки программирования» (Swift).
Вариант 28: найти все меньшие `n` числа Мерсенна (простые числа вида `2^p − 1`, где `p` — простое).

Это **макет проекта**: структура пакета, сигнатуры, валидация ввода и консольный интерфейс готовы,
а ключевая логика помечена `TODO` и пока возвращает заглушки.

└── Tests/Lab2MersenneTests/

## Что нужно сделать

- [ ] `PrimeMath.isPrime(_:)` — проверка числа на простоту (перебор делителей до `√n`).
- [ ] `MersenneNumbers.findMersenneNumbers(below:)` — перебор `p`, вычисление `(1 << p) - 1`,
      проверка `isPrime(p) && isPrime(candidate)`, остановка при `candidate >= n`.
- [ ] Снять `.disabled(...)` с тестов в `Tests/Lab2MersenneTests/MersenneTests.swift`.
- [ ] Дописать в отчёт выводы и скриншоты запуска.

Готовые части (можно использовать как образец): валидация (`empty`, `notANumber`, `notNatural`,
`tooLarge`, верхняя граница `maxAllowedN`), цикл ввода с повторным запросом, форматирование
результата через `CustomStringConvertible`.

## Сборка и запуск

Из папки `лаба 2`:

```bash
swift build            # сборка
swift test             # тесты (сейчас проходят только тесты валидации)
swift run Lab2Mersenne # запуск
```
